# 🚀 AprendeIT — Landing Page Estática

Landing page estática oficial para **AprendeIT**, academia digital de tecnología, desarrollo de software, inteligencia artificial y automatizaciones.

---

## 🌟 Características

- **Diseño Moderno & Responsivo**: Tipografía cuidada (*Manrope* + *DM Mono*), modo oscuro nativo, gradientes y microanimaciones interactivas.
- **Catálogo Interactivo de Cursos**: Exploración dinámica de programas (*FastAPI & Microservicios*, *Automatizaciones con IA*, *Python Profesional*, *DevOps Cloud*) con modal detallado de temarios, precios y docentes.
- **Simulador de Precios y Cuotas**: Cálculo dinámico en moneda local (ARS) y USD.
- **Integración Directa con WhatsApp**: Enlaces directos para consultas e inscripciones personalizadas.
- **Secciones Completas**:
  - Hero con propuesta de valor clara.
  - Métricas y testimonios de la comunidad.
  - Perfil del docente (Jeremías Toledo).
  - Metodología de aprendizaje en 4 fases.
  - Preguntas Frecuentes (FAQ) interactivas tipo acordeón.
  - Acceso directo al Aula Virtual.

## 💻 Cómo Ejecutar en Local

No requiere dependencias ni compilación. Podés abrir `index.html` directamente en tu navegador o usar cualquier servidor local:

### Opción 1: Con Python
```bash
python -m http.server 8000
```
Luego abrí `http://localhost:8000` en tu navegador.

### Opción 2: Con Node.js / npx
```bash
npx serve
```

### Opción 3: Con Live Server (VS Code)
Hacé clic derecho en `index.html` y seleccioná **"Open with Live Server"**.
